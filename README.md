# Music Loader (Fabric, Minecraft 26.3)

Музыкальный плеер в меню паузы (Esc).

## Сборка
Нужны Java 25 и Gradle 9.6.0.

    gradle wrapper --gradle-version 9.6.0   # один раз, создаст gradlew
    ./gradlew build                          # jar будет в build/libs/musicloader-1.0.0.jar

Или открой папку в IntelliJ IDEA и запусти задачу `build`.

## Установка
1. Fabric Loader 0.20.0 (или новее) для Minecraft 26.3.
2. Fabric API 0.165.0+26.3 (или новее для 26.3) в папку `mods`.
3. `musicloader-1.0.0.jar` в папку `mods`.

## Использование
- При первом запуске создаётся папка `.minecraft/musicloader` с файлом ИНСТРУКЦИЯ.txt.
- Положи туда .wav или .mp3 (имя: `Автор - Название.wav`) или перетащи файл мышкой в окно паузы.
- Иконка: .png с тем же именем (если нет - пустое место в кружке).
- Esc: кружок с музыкой, < и > выбор песни, треугольник сверху - пауза/пуск,
  зелёная полоса снизу - прогресс (клик - перемотка), "Добавить текст" - текст снизу меню.
